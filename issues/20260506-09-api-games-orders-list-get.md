# 提出済み命令一覧取得 API の実装

## エンドポイント

- GET /games/:game_uuid/orders

## パスパラメータ

- `game_uuid` (`string`): 対象の卓の UUID（UUID v7 形式）

## 機能

- 自身が提出済みの命令一覧を返す。他国軍に対する仮定命令も含む。
- 参加者のみ取得可能。

## 成功レスポンス

- Status: `200 OK`
- 未決（`order_id`, `unit`, `order_kind`, `status` 等を含む配列）

## エラー

- 401: 未認証
- 403: 参加者でない場合
- 404: 卓が存在しない場合

## その他

- 未決
