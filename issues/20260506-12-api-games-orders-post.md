# 仮想命令・建造命令登録 API の実装

## エンドポイント

- POST /games/:game_uuid/orders

## パスパラメータ

- `game_uuid` (`string`): 対象の卓の UUID（UUID v7 形式）

## リクエストボディ

- 未決（`unit`, `order_kind`, `target` 等）

## 機能

- 他国軍に対する仮定命令、または調整フェイズの建造命令を登録する。
- 参加者のみ操作可能。

## 制限

- 未決（仮定命令は外交フェイズのみか、建造命令は調整フェイズのみかを明示する）

## 成功レスポンス

- Status: `201 Created`
- 未決（作成された命令の `order_id` を含むか）

## エラー

- 400: リクエスト形式違反、または存在しないユニット/地域
- 401: 未認証
- 403: 参加者でない場合
- 404: 卓が存在しない場合
