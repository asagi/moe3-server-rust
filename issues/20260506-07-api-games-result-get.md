# 命令解決履歴取得 API の実装

## エンドポイント

- GET /games/:game_uuid/result/:turn

## パスパラメータ

- `game_uuid` (`string`): 対象の卓の UUID（UUID v7 形式）
- `turn` (`integer`): ターン番号（未決：0 始まりか 1 始まりか）

## 機能

- 指定したターンの命令解決結果（全勢力の命令・結果）を返す。
- 未決（参加者のみ閲覧可能か、認証不要か）

## 成功レスポンス

- Status: `200 OK`
- 未決（各命令の `unit`, `order_kind`, `status` 等を含む配列）

## エラー

- 404: 指定した卓またはターンが存在しない場合、あるいはターンがまだ解決されていない場合

## その他
