# 外交履歴取得 API の実装

## エンドポイント

- GET /games/:game_uuid/logs/:turn

## パスパラメータ

- `game_uuid` (`string`): 対象の卓の UUID（UUID v7 形式）
- `turn` (`integer`): ターン番号（未決：0 始まりか 1 始まりか）

## 機能

- 指定したターンの外交メッセージ履歴を返す。
- 未決（参加者のみ閲覧可能か、認証不要か）
- 未決（「外交履歴」の具体的な内容。外交チャットメッセージ、システムメッセージ等の区別）

## 成功レスポンス

- Status: `200 OK`
- 未決

## エラー

- 404: 指定した卓またはターンが存在しない場合

## その他

- 未決
