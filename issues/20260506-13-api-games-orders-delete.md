# 仮想命令・建造命令削除 API の実装

## エンドポイント

- DELETE /games/:game_uuid/orders/:order_id

## パスパラメータ

- `game_uuid` (`string`): 対象の卓の UUID（UUID v7 形式）
- `order_id` (`integer` or `string`): 命令 ID（未決：型・形式）

## 機能

- 指定した仮定命令または建造命令を削除する。
- 参加者のみ操作可能。

## 制限

- 未決（自国ユニットへの通常命令は削除不可か、仮定命令・建造命令のみ削除可能か）
- フェイズ解決後の命令は削除不可。

## 成功レスポンス

- Status: `204 No Content`

## エラー

- 401: 未認証
- 403: 参加者でない場合、または削除権限がない場合
- 404: 卓または命令が存在しない場合
