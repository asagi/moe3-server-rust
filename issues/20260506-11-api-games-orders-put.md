# 命令変更 API の実装

## エンドポイント

- PUT /games/:game_uuid/orders/:order_id

## パスパラメータ

- `game_uuid` (`string`): 対象の卓の UUID（UUID v7 形式）
- `order_id` (`integer` or `string`): 命令 ID（未決：型・形式）

## リクエストボディ

- 未決（変更後の命令内容。`order_kind`, `target` 等）

## 機能

- 既存の命令を上書き変更する。
- 参加者のみ操作可能。自国ユニットへの命令のみ変更可能（未決：仮定命令の変更可否）。

## 制限

- メインフェイズ（外交・撤退・調整）中のみ操作可能。
- フェイズ解決後の命令は変更不可。

## 成功レスポンス

- Status: `200 OK`
- 未決

## エラー

- 400: リクエスト形式違反
- 401: 未認証
- 403: 参加者でない、または自国ユニットでない
- 404: 卓または命令が存在しない場合
