# 開戦前夜の初期占領地に、補給都市でない本国の陸地を加える依頼

盤面取得 API（`GET /games/:game_uuid/board`）で開戦前夜の盤面を取ると、`territories` が補給都市の 22 か所だけになっている。フロント（moe3-front-rr）の地図は占領情報で陸地を塗り分けているので、各国の本国のうち補給都市でない陸地が「どこの国でもない」色になってしまう。

項目ごとに「必須」「任意」を付けた。

---

## 原因

`Phase::new_ready()`（`server/src/domain/models/phases/method.rs`）の初期領土生成が、補給都市の 22 か所しか作っていない。

占領判定（`occupy`）では、ユニットのいる陸地は補給都市でなくても占領情報に加えている。そのため、ゲームが進めば補給都市でない陸地も塗られる。ただ、開戦時点の本国の陸地は塗られないままになる。

## 1. 初期占領地に 20 か所を加える【必須】

`new_ready()` の初期領土に、次の 20 か所を加えてほしい。今ある補給都市 22 か所と合わせて 42 か所になる。フロントの初期盤面（`boardDefaults.json` の `initialTerritories`）と同じ内容。

| 国           | 加える地域（補給都市でない本国の陸地）                 |
| ------------ | ------------------------------------------------------ |
| オーストリア | `boh`（ボヘミア）・`gal`（ガリツィア）・`tyr`（チロル） |
| イギリス     | `cly`（クライド）・`wal`（ウェールズ）・`yor`（ヨーク） |
| フランス     | `bur`（ブルゴーニュ）・`gas`（ガスコーニュ）・`pic`（ピカルディー） |
| ドイツ       | `pru`（プロイセン）・`ruh`（ルール）・`sil`（シレジア） |
| イタリア     | `apu`（アプリア）・`pie`（ピエモンテ）・`tus`（トスカナ） |
| ロシア       | `fin`（フィンランド）・`lvn`（リヴォニア）・`ukr`（ウクライナ） |
| トルコ       | `arm`（アルメニア）・`syr`（シリア）                   |

- 補給都市の数は変わらない。そのため、調整フェイズのユニット数、滅亡の判定（補給都市とユニットがどちらもゼロ）、単独勝利の判定には影響しないはず。
  - `count_supply_centers` は補給都市だけを数えている（`Province::is_supply_center` で絞っている）ことを確認した。ほかに `territories` の件数をそのまま補給都市の数として使っている処理があれば、同じように直してほしい。
- 開戦前夜の盤面の編集で、これらの地域の占領を外したり別の国にしたりできるのは、今の編集 API のままでよい。

## 2. 作成済みの卓の扱い【確認】

この変更より前に作った卓は、開戦前夜のフェイズに 22 か所しか持っていない。どう扱うか相談したい。フロント側の案は次のとおり。

- **最新フェイズが開戦前夜の卓**（まだ始まっていない卓）：20 か所を加える移行処理を入れてほしい【必須】。
  - ただし、すでに盤面の編集でその地域の占領を設定・解除していた場合は、上書きしないでほしい。ただ、編集の履歴がなければ見分けられない。開戦前夜の盤面の編集は今回の依頼（20261125-03）で初めてできるようになるので、本番の卓で編集済みのものはないはず。そのため「開戦前夜の卓にはそのまま加える」でよいと考えている。
- **すでに始まっている卓**：そのままにする。補給都市でない陸地の占領は勝敗に関係しないので、地図の色が開戦時の想定と違うだけで済む。直したい場合は、ユーザーが盤面の編集で個別に設定できる。

## 3. テスト

- `new_ready()` の盤面に、補給都市 22 か所と補給都市でない陸地 20 か所の、合わせて 42 か所の占領情報がある。
- 開戦前夜から 1901 年春に進んだとき、42 か所がそのまま引き継がれる。
- 盤面取得 API が、開戦前夜の盤面で 42 か所を返す。
- 補給都市でない陸地を占領していても、調整フェイズのユニット数や滅亡の判定が変わらない。
