# 国ごとの「不在時間」（最終アクセスからの経過時間）を返す依頼

フロント（moe3-front-rr）の命令画面の状況表（7 か国の補給都市・陸軍・海軍・即時進行）に、**「不在時間」列**を足す。国画像のすぐ右に置き、担当者が最後にアクセスしてからの経過時間を出す。

今の `GET /games/:game_uuid/board` は `powers[].is_idle`（無政府状態か）しか返さず、経過時間が分からないので、これを返してほしい。

項目ごとに「必須」「任意」を付けた。フィールド名は案なので、サーバー側の命名規則に合わせて変えてよい。

---

## 前提（フロント側で決まっている仕様）

- 表示は、1 時間未満は `0分`〜`59分`（1 分刻み）、1 時間以上は `1時間`〜（1 時間刻み）。端数は切り捨て。
- 無政府状態の国は `無政府` と出す。判定は**サーバーの `is_idle` に従う**（フロントでは閾値を計算しない）。短期の卓（放置上限 60 分）は `59分` の次が `無政府` になる。
- 滅亡した国は `—`。過去のシーズンは列を出さない。
- **全員に見せる**（参加者・第三者・未ログインを問わない）。他国がいつアクセスしたかは駆け引きに使える情報だが、見せる方針で決まっている。
- 経過時間はフロントが 1 分ごとに数え進める。

## 1. `PowerStatus` に経過時間を足す【必須】

`GET /games/:game_uuid/board` の `powers[]` に `absent_minutes`（`number | null`）を足してほしい。

```json
{
  "power": "f",
  "supply_centers": 5,
  "armies": 2,
  "fleets": 3,
  "needs_action": true,
  "progress_consented": false,
  "is_idle": false,
  "absent_minutes": 42,
  "is_eliminated": false
}
```

- 値は、担当者の `users.last_access_at` から**レスポンスを作った時点まで**の経過分数（切り捨て）。
- 時刻（`last_access_at`）そのものではなく経過分数にしてほしい。ブラウザの時計がずれていても正しく出せるため（フロントは受け取った時点から数え進める）。
- `null` にするのは次の場合：
  - 過去のフェイズ（`is_idle` と同じ）
  - 担当者がいない国
  - フェイズが無い卓（`powers` 自体が空なので実質なし）
- 滅亡した国も値は返してよい（フロントは `—` を出す）。
- `last_access_at` はユーザー単位なので、ほかの卓へのアクセスでも縮む。無政府の判定と同じ値なので、それでよい。

## 2. 無政府状態の変化を SSE で知らせる【任意】

今は無政府状態への移行・復帰では `board` イベントを送らない（`messages-stream` のドキュメントのとおり）。そのため、状況表の `無政府` 表示や行の赤背景は、ほかのきっかけで読み直すまで変わらない。

- `mark_idle_players` で `is_idle` を立てたとき、`restore_returned_player` で復帰させたときに、その卓へ `board` イベントを送ってほしい。
- 復帰は `power_returned` のシステムメッセージが流れるので、フロントはそれを合図にも読み直せる。移行のほうだけでも助かる。

## 3. ドキュメント

- `docs/api/games-game-uuid-board__get.md` の `PowerStatus` に `absent_minutes` を追記。
- （2 をやる場合）`docs/api/games-game-uuid-messages-stream__get.md` の `board` イベントの送るタイミングを更新。

## 4. テスト

- `absent_minutes` が `last_access_at` からの経過分数（切り捨て）になる。
- 過去のフェイズ・担当者のいない国は `null`。
- 認証なしでも返る。
