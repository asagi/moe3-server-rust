# 撤退フェイズ・調整フェイズのチャット書き込み禁止の依頼

撤退フェイズと調整フェイズのあいだは、チャットへの書き込みを全員禁止にする。フロント（moe3-front-rr）は対応済みで、サーバー側の変更を待っている。

- フロントは、このあいだ参加者にもログビューアー（読むだけの画面）を出す。
- フェイズが切り替わった瞬間に画面を切り替えたいので、SSE でフェイズの切り替えを知らせてほしい。

---

## 1. 発言 API（`POST /games/:game_uuid/messages`）【必須】

最新フェイズが撤退フェイズ（`SpringRetreat` / `FallRetreat`）か調整フェイズ（`Adjustment`）のときは、すべての発言を拒否する。

- 対象は、通常の発言・独り言・密談・管理人発言（`as_admin: true`）のすべて。
- エラーは 403。コードは新しく `phase_not_accepting_messages` を追加する案（既存の `game_not_accepting_messages` を流用してもよい。どちらにしたか教えてほしい）。

## 2. SSE に `phase` イベントを追加【必須】

`GET /games/:game_uuid/messages/stream` で、最新フェイズの種別が変わったら `phase` イベントを送る。

```text
event: phase
data: {"season":"1901s","phase_kind":"retreat"}
```

| フィールド   | 型       | 説明                                                                                             |
| ------------ | -------- | ------------------------------------------------------------------------------------------------ |
| `season`     | `string` | 切り替わったあとのシーズン（`current_turn()` と同じ形）                                          |
| `phase_kind` | `string` | 切り替わったあとのフェイズ種別。`GET /games/:game_uuid` の `phase_kind` と同じ値（`ready` / `main` / `retreat` / `adjustment` / `debrief`） |

- 今の `season` イベントは、シーズンが変わったときだけ届く。メインフェイズから撤退フェイズへ移ってもシーズン（`1901s`）は変わらないので、フロントはこの切り替えに気づけない。
- `StreamState` に今のシーズンと同じようにフェイズ種別も持たせて、`collect_stream_update` で比べる形を想定している。
- シーズンも変わる切り替え（例：撤退フェイズ → 秋のメインフェイズ）では、今までどおりの `season` イベントと `phase` イベントを両方送る。順番は問わない。

## 3. テスト

次のテストを追加してほしい。

- 撤退フェイズと調整フェイズでは、通常の発言・独り言・密談・管理人発言のすべてが拒否される。
- メインフェイズ・開戦前夜・感想戦では、今までどおり書き込める。
- メインフェイズから撤退フェイズに変わったら、SSE に `phase` イベントが届く。
