# 卓主権限で次回更新時刻を延長する API の実装

## エンドポイント

- PUT /admin/games/:game_uuid/next-update-at

## パスパラメータ

- `game_uuid` (`string`): 対象の卓の UUID（UUID v7 形式）

## リクエストボディ

- `season` (`string`): 季節（例: `"ready"`, `"1901s"`, `"1903f"`, ...）
- `next_update_at` (`String`): 変更後の次回更新時刻（YYYY-mm-dd HH:MM 形式かつ JST）

## 機能

- 現在の卓（Game）の `next_update_at` を指定時刻で更新する。
- リクエストが成功した場合はシステムメッセージを保存する。
  - "次回更新時刻が {next_update_at} に変更されました。"
  - {next_update_at} はリクエストパラメータそのままを出力する。

## 制限

- 卓主以外からのリクエストはエラーとする。
- 準備フェイズ、メインフェイズ以外のリクエストはエラーとする。
  - 調整撤退フェイズでは卓主が他プレイヤーの意向を確認できないため。
  - 感想戦フェイズは延長の必要がないため。
- 指定時刻が変更前の `next_update_at` よりも過去の場合はエラーとする。
  - 本機能は更新時刻の延長のためにのみ使用する想定。
- MM は 10 分刻みとする。
- リクエストパラメータの `next_update_at` の未指定、`null`、形式違反はエラーとする。

## その他

- メッセージ出力の都合上、卓更新処理よりも先に処理する。
